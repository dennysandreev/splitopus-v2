# Splitopus v2 🐙

**Splitopus** — это Telegram Mini App для учета совместных расходов в путешествиях и компаниях.
Позволяет создавать поездки, добавлять участников, вести учет трат в разных валютах и автоматически рассчитывать долги ("кто кому сколько должен").

## 🚀 Возможности

- **Мультивалютность:** Поддержка THB, RUB, USD, EUR и конвертация по курсу.
- **Гибкое разделение:** Поровну, на выбранных участников или ручной ввод сумм.
- **Семейные аккаунты (Партнерство):** Возможность привязать одного пользователя к другому в рамках конкретной поездки (платит "Мастер", тратят оба, долг считается на семью).
- **Рулетка:** Случайный выбор того, кто угощает компанию (без записи долга).
- **Экспорт:** Выгрузка всех трат в CSV.
- **Telegram Mini App:** Удобный интерфейс прямо внутри Telegram.

## 📂 Структура проекта

*   `backend/` — Python (FastAPI + SQLite + Aiogram/Telebot).
    *   `api.py` — REST API для Mini App.
    *   `bot.py` — Логика Telegram-бота.
    *   `src/` — Бизнес-логика, работа с БД.
*   `frontend/` — React + TypeScript + Vite + Tailwind CSS.
    *   `src/screens/` — Экраны приложения (Список поездок, Баланс, Создание траты и т.д.).
    *   `src/store/` — Zustand store для управления состоянием.
*   `docker-compose.yml` — Конфигурация для деплоя (Backend, Frontend, Nginx, Certbot).
*   `nginx.conf` — Конфигурация Nginx (проксирование запросов, SSL).

## 🛠 Установка и запуск (Локально)

### Бэкенд

1.  Перейдите в папку `backend`:
    ```bash
    cd backend
    ```
2.  Создайте виртуальное окружение и установите зависимости:
    ```bash
    python3 -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt
    ```
3.  Создайте файл `.env` и добавьте токен бота:
    ```env
    BOT_TOKEN=ваш_токен
    ```
4.  Запустите сервер:
    ```bash
    uvicorn api:app --reload
    ```

### Фронтенд

1.  Перейдите в папку `frontend`:
    ```bash
    cd frontend
    ```
2.  Установите зависимости:
    ```bash
    npm install
    ```
3.  Запустите сервер разработки:
    ```bash
    npm run dev
    ```

## 🐳 Деплой (Docker)

Проект настроен для запуска через Docker Compose с автоматическим получением SSL-сертификатов через Certbot.

1.  Настройте переменные окружения в `docker-compose.yml` или `.env`.
2.  Запустите контейнеры:
    ```bash
    docker-compose up -d --build
    ```

## 🔄 Миграции и обновления

### Партнерство на одну поездку (v2.1)
В версии 2.1 изменена логика привязки партнеров. Теперь поле `linked_to` находится в таблице `trip_members` (связь М-ко-М), а не в `users`. Это позволяет иметь разных партнеров в разных поездках.
Миграция данных осуществляется скриптом `backend/migrate_partnerships.py`.

## 🤝 Разработка

*   **Бэкенд:** При изменении схемы БД не забудьте обновить `backend/src/schema.sql`.
*   **Фронтенд:** Сборка осуществляется через Vite (`npm run build`).
